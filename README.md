## 🎯 Objetivo
Compreender o funcionamento e as aplicações dos quatro principais tipos de listas dinâmicas:

- Lista Simplesmente Encadeada  
- Lista Duplamente Encadeada  
- Lista Circular Simples  
- Lista Duplamente Circular  

A atividade tem como propósito aplicar conceitos de **encadeamento** e **alocação dinâmica** por meio de exemplos práticos implementados em linguagem C.
